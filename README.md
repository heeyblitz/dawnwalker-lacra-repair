# The Blood of Dawnwalker — Lacra Questline Repair

> ⚠️ **BETA / EXPERIMENTAL**

A save repair tool for restoring Lacra's questline, including
"A Friend Like This" (q103), without having to replay a large
portion of your playthrough.

## What is this?

This tool was created after getting locked out of Lacra's questline
during a playthrough and discovering the problem several days later.

The original q103 restoration work was based on the save research and
fix published by **AiKiKun**, developed together with **Claude Opus 5**.

This project builds on that work and adds an experimental repair for
Lacra's actor/persistence state when restoring q103 alone is not enough.

⚠️ The Lacra-specific repair is experimental and has only been
validated on a limited number of saves. Make backups before using it.
